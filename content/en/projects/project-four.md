## Challenge

The portfolio needed to make visual work feel immediate while still giving each project enough context. The main challenge was keeping the page expressive without making the content hard to scan.

## Approach

I structured the page around a strong media-first flow, then placed details and written notes below it. This keeps the first impression visual while still supporting a complete project story.

## Result

The page can now be used as a flexible project template for real screenshots, motion clips, and concise case-study writing.
