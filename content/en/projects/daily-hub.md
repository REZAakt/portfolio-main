## Project Overview

all the daily information you'd otherwise need to check different sites and apps for, gathered in one place.
DailyHub started as a simple project working with different APIs for university, which I continued developing and now mostly use myself to access the information I need faster.

## Approach

The project uses a range of different APIs to show users the information they need for each section.
The architecture is clean and modular — each section you see on the site is a separate module. This was also a way for me to practice controlling each module independently, so that in bigger future projects I can implement modular architecture properly and in the most optimized way possible, making it easy to switch to a microservices architecture if a project's scalability needs and user base grow.
